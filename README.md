# 2025-2 데이터사이언스 소프트웨어 캡스톤디자인 (6조 파시통통) - FitForU

## 1. 프로젝트 소개
**FitForU**는 전신 사진 한 장으로 사용자의 체형을 분석하고, 사용자가 보유한 옷을 기반으로 개인 맞춤 코디를 자동해주는 서비스입니다.
체형 분석, 의류 자동 태깅, 코디 추천까지의 전체 흐름을 자동화하여 사용자가 별도의 입력 없이도 자신의 체형과 옷장에 맞춘 스타일링을 제공받을 수 있도록 개발하였습니다.

## 2. 시스템 전체 구조
본 시스템은 **백엔드 FastAPI 서버**, **Supabase**, **모바일 프론트엔드** 구조로 구성됩니다.
전체 동작 흐름은 다음과 같습니다.

1.  **사용자 입력**: 전신 사진 업로드, 옷 사진 업로드
2.  **분석 단계**: 체형 분석 파이프라인, 의류 자동 태깅
3.  **추천 단계**: 기온 기반 필터링, 색 조합 및 체형 가중치 기반 점수화
4.  **출력**: 추천 코디 TOP-3, LLM 기반 코디 설명

## 3. 주요 기능

### 3-1. 체형 분석
남성과 여성 모델을 분리하여 개발하였습니다. **MediaPipe Pose**를 활용해 어깨-허리-엉덩이 너비를 추출한 뒤, 비율(R1, R2)에 따라 여성 4종, 남성 3종으로 체형을 분류합니다.
* **관련 코드**: `m_body_shape_pipeline.py` (남성 체형 분류), `w_body_shape_pipeline.py` (여성 체형 분류)

### 3-2. 의류 자동 태깅
**YOLO**를 이용해 의류의 bbox를 검출하고, **rembg**로 배경을 제거합니다. 이후, **EfficientNet B5** 기반 속성 분류를 통해 major, minor, fit, length, color 등 총 10개의 속성을 자동으로 판단합니다. 분석된 결과 이미지는 Supabase Storage에 업로드되어 디지털 옷장을 구축합니다.
* **관련 코드**: `clothes_pipeline.py`

### 3-3. 코디 추천 알고리즘
코디 추천 알고리즘은 사용자의 체형, 보유 의류 정보, 그리고 기온 데이터를 종합하여 가장 적절한 조합을 생성하는 방식으로 구성됩니다.
1.  **OpenWeather API**를 통해 현재 기온을 불러온 뒤, 계절적 특성에 맞지 않는 의류는 우선적으로 제거합니다.
2.  색 조합 확률(outer\*top, top\*bottom)을 기반으로 어울리는 상하의 조합을 생성합니다.
3.  체형별 가중치(score table)를 더해 코디의 적합도를 계산합니다.
4.  최종적으로 적합도가 높은 상위 3개의 코디를 선정하고, 각 코디에 대해 **LLM**이 자연스러운 스타일 설명을 생성하여 사용자에게 전달합니다.
* **관련 코드**: `recommendation_pipeline.py`

### 3-4. 서버 API 구조
FastAPI 기반 서버에서 다음과 같은 API를 제공합니다.

| Method | Endpoint | 설명 |
| :--- | :--- | :--- |
| `POST` | `/users/profile` | 사용자 성별 저장 |
| `POST` | `/user/analyze-shape` | 전신 사진 기반 체형 분석 |
| `POST` | `/clothes/upload` | 의류 이미지 업로드 및 자동 태깅 |
| `POST` | `/recommend/outfit` | 코디 추천(TOP-3) 생성 |
| `GET` | `/users/me` | 사용자 정보 조회 및 관리(유저 id, 성별, 체형, 옷장, 탈퇴) |

* **관련 코드**: `app.py`
